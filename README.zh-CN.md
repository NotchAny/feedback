# NotchAny 反馈

[English](./README.md)

这里是 NotchAny 的公开反馈区，用于收集功能建议和问题反馈。NotchAny 应用源代码保存在私有仓库中，不会在这里公开。

## 提交反馈

- **功能建议：** 请描述需要解决的问题、期望的使用流程，以及这个改动将如何改善 NotchAny。
- **问题反馈：** 请提供 NotchAny 版本、macOS 版本、复现步骤、期望行为和实际行为。
- 提交前请先搜索是否已有相同 Issue。

## 隐私

此仓库中的所有 Issue 和评论均为公开内容。请勿提交 License Key、账号或设备标识、邮箱、私人文件路径，以及包含个人信息的日志或截图。

官网：[notchany.com](https://notchany.com)
