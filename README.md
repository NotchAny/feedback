# NotchAny Feedback

这是 NotchAny 的公开反馈区，用于收集功能建议和问题反馈。NotchAny 应用源码保存在私有仓库中，不会在这里公开。

This is the public feedback tracker for NotchAny. The application source code remains in a private repository and is not published here.

## 提交反馈 / Submit feedback

- 功能建议 / Feature requests: describe the problem, expected workflow, and why it would improve NotchAny.
- 问题反馈 / Bug reports: include the NotchAny version, macOS version, reproduction steps, and expected behavior.
- 提交前请先搜索是否已有相同 Issue / Please search existing issues before opening a new one.

## 隐私 / Privacy

这里的 Issue 和评论对所有人公开。请勿提交 License Key、账号或设备标识、邮箱、私人文件路径，以及包含个人信息的日志或截图。

All issues and comments are public. Do not include license keys, account or device identifiers, email addresses, private file paths, or logs and screenshots containing personal information.

Website: https://notchany.com
