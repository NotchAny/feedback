# NotchAny Feedback

[简体中文](./README.zh-CN.md)

This is the public feedback tracker for NotchAny. The application source code remains in a private repository and is not published here.

## Submit Feedback

- **Feature requests:** Describe the problem, your expected workflow, and how the proposed change would improve NotchAny.
- **Bug reports:** Include your NotchAny version, macOS version, reproduction steps, expected behavior, and actual behavior.
- Please search existing issues before opening a new one.

## Privacy

All issues and comments in this repository are public. Do not include license keys, account or device identifiers, email addresses, private file paths, or logs and screenshots containing personal information.
